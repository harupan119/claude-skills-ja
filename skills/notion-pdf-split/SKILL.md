# notion-pdf-split — Notion に入れる前に PDF を削って分割する

Notion のファイル取り込みには**サイズと処理時間の上限**があり、大きなPDFはそのままでは入らないか、入っても中身が読めない状態になる。取り込む前にローカルで削って分ける。

**このスキルは Notion API を呼ばない。** ローカルファイルの加工だけで完結する。ページ本文への反映は `notion-router` の表から別のスキルを選ぶ。

## 使う場面

- PDFが大きすぎて Notion に取り込めない、取り込めても扱いにくい
- 表紙・目次など、先頭の数ページが不要（例：先頭2ページを落とす）
- 対象がローカルのファイルパスにある

## 手順

1. 入力パスが実在することを確認する
2. `scripts/notion_pdf_split.py` を `--drop-first` と `--split` を付けて実行する
3. **出力されたページ数を確認する**（削りすぎ・分割数の取り違えはここでしか気づけない）
4. 出力先の絶対パスを返す

## コマンド

```bash
python3 scripts/notion_pdf_split.py \
  --input "/absolute/path/to/file.pdf" \
  --drop-first 2 \
  --split 2
```

| 引数 | 既定 | 意味 |
|---|---|---|
| `--input` | 必須 | 入力PDFのパス |
| `--drop-first` | `0` | 先頭から落とすページ数 |
| `--split` | `2` | 出力を何分割するか（`1` なら分割せず削るだけ）|
| `--output-dir` | 入力と同じ場所 | 出力先ディレクトリ |

## 注意点

- **`--split 1` は「分割しない」**。先頭を削ったファイルが1つだけ出る。無効値ではない
- 出力は既定で入力と同じフォルダに書かれる。元ファイルは残る
- `pypdf` が無ければ一時的な venv に入れて、その Python で実行する
- 落としたページは復元できない。**元ファイルを上書きしない**ことを確認してから実行する

## 関連

Notion系スキルの使い分けは `notion-router` の表を参照。本スキルは**ファイルの前処理**であり、`notion-figure-insert`（PDF中の図をページ本文へ挿入）とは関心が異なる。
