# モード: academic（アカデミック）

対象: 大学レポート・論文・実験考察・仕様書・申請書の技術本文。提出先の書式規約がある場合は、その規約と併用する。

SKILL.md の第1〜3層で検出したあと、ここの方針で書き換える。`humanizer-ja-academic`（旧スキル）と matsui academic の規律を統合。**register（だ・である・無人称・客観）を維持したままAI臭だけ抜く。**

## 絶対にしないこと

- **ですます化しない。** だ・である調を最後まで保つ。
- **体温・本音・口語・一人称を入れない。** 「正直」「個人的には」「うちでは」「まだ試してない」は禁止。語り手は無人称。
- **断定の根拠を勝手に足さない。** 実測・論理で裏づけのない主張を作らない。
- casual の「声を入れる」「本人声紋」は**適用外**。

## 学術で特に効くルール

- **論理を運ぶ接続詞は保持する。** 「一方」「これに対し」「したがって」「ゆえに」「以上より」「先行研究では」は良い人間の文章の証。**意味を盛る語（〜の重要性を浮き彫りにし）だけ削り、論理を明示する語は残す。** 判定：その語が*意味を膨らませる*なら削除、*論理を明示する*なら保持。
- **接続詞を裸で消さない（最重要）。** 消して段落がブツ切れ（choppy）になるのは機械的AI除去の痕跡。接続を消すなら、別の接続で繋ぐ／前文のキーワードを次文頭で受ける／2文を1文に統合する、のいずれかで論理連結を必ず復元する。
- **段落結束チェック（最終必須）。** 各段落で、(a) 冒頭文が段落の主張を述べているか、(b) 2文目以降が接続詞かキーワード反復で前文に繋がっているか、(c) 段落間の対比・継続の標識（一方／これに対し／以上を踏まえると）が論理上必要な箇所に残っているか。編集で切れた連結は直す。
- **ヘッジは適正量を残す。** 観察・推測・二次的所見は「〜の可能性がある」「〜と関連していた」を1つ残す。実測・主結果は言い切ってよい。AI的な多層ヘッジ（〜の可能性が示唆されるかもしれないと考えられる）だけを1つに削る。
- **定型評価文を消す。** 「これは重要な知見である」だけの中身ゼロ文は削除。重要なら*なぜ*（機序・帰結・先行研究との対比）を書く。
- **意義づけの付け足し（-ing的構文）** は、空疎なら削除。ただし学術では考察自体は必要なので、実測の引用＋機序による解釈に置き換える（丸ごと無くすのではなく中身を入れる）。

## 太字とラベルの扱い（レポート実務で最も効く）

- **太字は用語の初出定義だけに使う、と一律に決める。** 主張の強調にも太字を使うと、読み手が太字の意味を一意に解釈できない。「太字を見たら定義される用語」に固定すると規則が単純になり、点検も機械的にできる。
- **`**〜する。** 本文` 形式の文頭太字ラベルは Claude / ChatGPT の最大の癖。** 太字を外し、その文をそのまま段落の冒頭文にする。結果として「冒頭文が段落の主張を述べる」形になり、上の段落結束チェックにも合う。**節見出しへの格上げは避ける**（既に3階層あるなら4階層目になり、第1層7の見出しの過剰構造化に触れる）。
- **`**ラベル**: 内容` の箇条書きも同じ癖。** ラベルを文の主題に組み込む（`- **チェイン法**は、…する方式である。`）。用語の初出であれば太字自体は残してよい。
- **体言止めのラベル＋句点（`**計測環境。** 単一の…`）は、太字を消すだけでは直らない。** 「計測環境。」という体言止めが残る。列挙を保ちたいなら「第一に」「第二に」「最後に」の序数を使った散文に書き換える。走査性は序数で確保できるので、ラベルは要らない。
- **除去の後始末を必ずする。** 句点直後の半角空白（`。 `）が残る。SKILL.md のチェックリスト参照。

## 図表を含む文書の監査

- **図の中の日本語も本文と同じ用語に揃える。** 軸ラベル・凡例・タイトルは本文の定義から外れやすい。本文で「不成功探索」と定義したのに図だけ「失敗探索」、本文が「除算法」なのに図は `mod`、といった揺れが実際に出た。図は別ファイル（作図スクリプト）で生成されるため、本文だけを直しても揺れが残る。
- **図のキャプションは図を実際に開いて書く。** データ名や実験名から推測して書くと、別の量のキャプションを付ける。「探索時間」と書いた図が実は最長チェイン長だった実例がある。読み手はどちらが誤りか判定できないため、重要度は高い。
- **図の凡例に数学記号を使うときは字形の有無を確かめる。** matplotlib で日本語フォントを指定すると `⌈ ⌉` などが無く豆腐になる。語で書く（「log₂(N+1) の切り上げ」）。
- **参照線・目安線のラベルが数学的に正しいか確かめる。** 「上界」と書いた線が実測を下回っていた実例がある（切り上げを省いたため）。図の主張は本文の式と一致させる。
