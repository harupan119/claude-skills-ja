# モード: casual（口語）

対象: ブログ・note・SNS・日記・砕けたメール。**温度を入れてよい／入れるべき**レジスタ。

SKILL.md の第1〜3層で検出・除去したあと、ここの方針で**書き換え**る。検出ルールは繰り返さない（SKILL.md参照）。

## 文体

- ですます調でもタメ口でもよい。文脈に合わせる。一人称（自分・俺・私）OK。
- 主観・意見・体験を出してよい。中立に逃げない。

## 声を入れる（パターンを消すだけにしない）

無菌室の文章を避け、人間の温度を入れる:

1. **体験を1つ入れる。** 「自分の場合は」「うちでは」「実際に試したら」。
2. **意見を1つ入れる。** 「正直これは微妙だと思ってます」「個人的にはこっち」。
3. **リズムを崩す。** 長い文の後に短い断定。丁寧語の後に体言止め。
4. **複雑さ・不完全さを認める。** 「すごいけど、ちょっと薄気味悪い」「ここはまだ自信ない」。
5. **感情を具体的に。** 「懸念される」→「深夜3時に勝手にコードが量産されてるのを想像すると、なんとも言えない気持ちになる」。

※casual に限り、**意図的な短文リズム**（体言止めの連射など）は許容（SKILL.md「パラタキシス回避」の例外）。ただし全文が同じ短さに均一化したらAI的なので、長い文と混ぜる。

## 「自分らしさ」較正（本人の声紋）

本人が書くテキスト・本人名義の文章を humanize するときは、一般的な「人間らしさ」で止めず**本人の文体指紋**に寄せる。AI臭を抜いただけの文章は無味無臭になり、「誰でもない人が書いた文章」になるため。

指紋は `voice-print-ja.md` に置く。**このファイルは各自で作る。**書き手の私的な文章（日記・雑記・SNS）から抽出するので、内容は個人情報として扱い、共有・公開しない。雛形と作り方は [voice-print-ja.template.md](voice-print-ja.template.md)。

`voice-print-ja.md` が無ければこの節は飛ばし、一般的な口語の humanize で止める。

**やりすぎ厳禁**：指紋は「らしさの方向」であって、全文をその語彙で埋める指示ではない。1〜2箇所効かせれば足りる。

## このモードでやらないこと

- 学術・対外文書には使わない（→ academic / business）。
- 事実を主観で歪めない。体験は本物だけ（捏造禁止、SKILL.md §41相当）。
