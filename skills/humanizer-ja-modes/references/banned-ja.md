# 禁止語・禁止フレーズ集（日本語）

AI生成文の統計的マーカー。出てきたら原則すべて書き換える。ただし**単独で1個出ただけでは確定しない**（誤検出ガードはSKILL.mdの「誤検出を避ける」を参照）。クラスタで出たら確定。

出典の系譜: Wikipedia「Signs of AI writing」(WikiProject AI Cleanup) / blader/humanizer / jalaalrd/anti-ai-slop-writing(banned-words) / ai-writing-detox / humanizer-ja。

---

## 1. 禁止語彙（定型評価語・盛り語）

消すか、具体（数値・機序・固有名）に置き換える。

- 浮き彫りにする／浮き彫りになった
- 注目に値する／注目を集めている／今後の展開が注目される
- 重要な示唆を与える／示唆に富む
- 計り知れない／枚挙にいとまがない
- 多面的な／包括的な／多角的な／重層的な
- 画期的な／革新的な／先進的な／最先端の
- 飛躍的な／劇的な／圧倒的な／目覚ましい
- 不可欠な／極めて重要な／必要不可欠な／欠かせない
- 大きな役割を果たす／重要な役割を担う
- 〜の根幹をなす／〜の礎となる／〜の象徴である
- 〜を物語っている／〜を如実に示している
- まさに〜と言える／〜にほかならない
- 著しい／顕著な／特筆すべき
- 豊かな（比喩）／彩る／織りなす／紡ぐ（比喩）

## 2. 禁止カタカナ語（和語・定訳に戻す）

技術用語の定訳（API・トランザクション等）は保持。比喩・バズワード用法のみ対象。

- レバレッジ → 活かす／使う
- ソリューション → 解決策／仕組み
- イノベーティブ／イノベーション → 新しい〜／（具体を書く）
- トランスフォーメーション → 変革／変える
- アプローチ → やり方／方法（文脈で残してもよい）
- シームレス → なめらか／途切れない（多くは虚偽なので削除）
- ロバスト → 頑健／壊れにくい
- スケーラブル → 規模を広げられる
- エンパワー → （何ができるかを具体で）
- パラダイムシフト → （具体的に何が変わったか）
- シナジー → 相乗効果／（書き換え）
- コミットメント → （何を約束したか具体で）

## 3. 禁止フレーズ（説教前置き・つなぎ・締め）

### 前置き（throat-clearing）— 原則まるごと削除
- 「ここで重要なのは〜という点です／だ」
- 「〜について理解しておく必要があります／がある」
- 「注意すべき点として」「押さえておきたいのは」
- 「まず前提として」「結論から言うと」（多用時）
- 「近年、〜が急速に進展しており」「〜が大きな注目を集めています」
- 「本記事では〜について解説します」「ここでは〜を見ていきましょう」
- 「言うまでもなく」「ご存知の通り」

### 権威トロープ（深掘りを装う）
- 「本質的には」「突き詰めると」「煎じ詰めれば」
- 「本当に重要なのは」「真に問われているのは」
- 「核心は」「要は」「結局のところ」「畢竟」

### 修辞的フック（作り物の率直さ）
- 「正直に言うと、」「ぶっちゃけ」「ここだけの話」（演出としての単独フック）
- 「実のところ」「率直に言って」（中身のない前振り）
- ※口語の中で自然に使うのは可。単独の「演出ポーズ→種明かし」型だけが対象。

### つなぎ（接続詞の多用）— 密集したら半分削る
- 一方で／しかしながら／加えて／さらに／また／そして
- このように／そのため／したがって／ゆえに
- とりわけ／なかでも／いずれにせよ

### 締め（generic positive conclusion）— 書き換え必須
- 「今後の展開が注目されます／期待されます」
- 「ますます重要になると考えられます／思われます」
- 「〜の可能性を秘めています」
- 「明るい未来が待っています」「大きな一歩と言えるでしょう」
- 「〜が求められています」（主語ぼかしの締め）

## 4. 婉曲・ヘッジ（言い切る or 削る）

- 〜と言えるでしょう → 言い切る（だ・である／です）
- 〜ではないでしょうか／〜ではないだろうか → 言い切る
- 〜かもしれません（過剰連発時）→ 1つに絞る
- 〜と考えられます／〜と思われます（無人称の逃げ）→ 根拠を出すか言い切る
- 〜的には／〜という意味では（多用時）→ 削る

## 5. 冗長表現（短縮）

| 冗長 | 短く |
|------|------|
| することができます／することが可能です | できます／できる |
| 〜という形になります | 〜です／〜だ |
| 〜を行います | 〜します |
| 〜に他なりません | 〜だ |
| 〜ことが挙げられます | 〜がある／（直接書く） |
| 〜する必要があります（多用）| 〜する／〜したい |
| 〜していきたいと思います | 〜する |
| 〜させていただきます（過剰）| 〜します |

## 6. チャット残骸（コンテンツに混入したAI応答の名残）

- 「素晴らしいご質問ですね！」「鋭いご指摘です」「おっしゃる通りです」
- 「お役に立てれば幸いです」「ご不明な点があればお知らせください」
- 「いかがでしたか？」「参考になれば嬉しいです」
- 「〜しましょうか？」「〜を続けましょうか？」「例を挙げましょうか？」
- 「もちろんです！」「承知しました！」（本文中に残ったもの）

## 7. 知識カットオフ・推測埋め（出典がないなら認める or 消す）

- 「2024年時点の情報では」「私の知る限りでは」（本文に残った免責）
- 「詳細は公開されていませんが」「限られた情報によれば」
- 「〜と見られます」「〜とされています」（出典なしの伝聞化）
- 「おそらく〜で育ち」「〜と推測されます」（プロフィールの空想埋め）
→ 分からないことは「分からない」と書くか、その文を削る。憶測を事実の体裁にしない。

## 8. 時期別マーカー（参考）

- 2023〜2024（GPT-4期）: 〜を浮き彫りに／〜と言えるでしょう／多面的／包括的／〜が期待される／レバレッジ／シームレス
- 2024〜2025: 〜を示しており／〜に寄与し／さらに／加えて
- 2025以降: 説教前置き＋三点セット＋汎用ポジティブ締めの「型」そのもの

この一覧は時期を限ったスナップショットである。Kobak et al. (2025) は2010〜2024年の PubMed 抄録1,500万件超で語の頻度の変化を調べ、2024年に急増した「文体語」379語のうち66%が動詞、14%が形容詞だったと報告している。コロナ禍の時期に急増した語がほぼすべて内容語（respiratory、remdesivir など。急増した内容語の79.2%は名詞）だったのとは性質が違う。英語の例では delves、underscores、showcasing、pivotal、intricate が挙がる。つまりマーカーになるのは話題の語ではなく**言い回しの語**で、上の時期別マーカーのとおり、どの語が目立つかはモデルの世代で変わる。語のリストだけに頼らず、第3層の構造（型）を見ること。
